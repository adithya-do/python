# DBA Admin & Health Check Tool

A full-featured web-based administration and health monitoring tool for Oracle RAC databases and Linux servers, built with Python 3.9+ / Flask.

---

## Features

### Oracle Module
- **Dashboard view** — DB name, environment, hostnames, full DB version (from `dba_registry`), DB size, instance count (red if any down), open mode, status, last checked, error
- **Check All** — parallel background health check across all registered databases
- **Detail tabs per database:**
  - **Overview** — RAC instances, DB properties, key parameters, component registry
  - **Tablespaces** — usage stats, datafile list, add datafile, resize datafile
  - **Performance** — top wait events, top SQL by elapsed time, ASH (last 15 min)
  - **Sessions** — search by SID/user/machine, kill session (admin only)
  - **Users** — account status, segment size, color-coded status
  - **Backups** — RMAN backup job history, archive gap, FRA usage
  - **Run Command** — SELECT with 50-row pagination (load-more on demand), DML with commit, schema selection

### Linux Module
- **Server inventory** — name, IP, environment, status, OS version, memory, memory %, CPUs, worst disk %, uptime, last checked, error
- **Check All** — parallel SSH health checks across all registered servers
- **Detail tabs per server:**
  - **System** — hostname, OS, kernel, architecture, uptime, load, dmesg errors
  - **CPU** — model, count, load avg, top CPU processes, per-core mpstat
  - **Memory** — `free -h`, `/proc/meminfo`, vmstat, top memory processes
  - **Disk** — color-coded `df -Ph`, iostat, lsblk
  - **Process** — `ps aux` with live search filter
  - **Network** — interfaces, listening ports, established connections, routes
  - **Run Command** — arbitrary SSH command execution

### Dashboard
- Stats: total/healthy Oracle DBs, total/healthy Linux servers
- Quick status tables with last-checked status
- Pie charts for DB and server health ratios

### Settings
- **Email/SMTP** — configure alerts, test email send
- **Credential Store** — AES-256 encrypted credential storage for Oracle and SSH connections
- **User Management** — add/edit/disable users, assign admin or user roles
- **Task History** — full audit log with output, searchable and filterable, purge old records

## Requirements

- Python 3.9+

- Network access to target Oracle databases and Linux servers

## Quick Install

```bash
# Clone or copy the application directory
git clone <repo_url> /opt/dba_admin_tool  # or copy files

# Run the installer as root
cd /opt/dba_admin_tool
sudo bash install.sh
```

The installer will:
1. Install system dependencies (python3, gcc, etc.)
2. Create a `dbaadmin` service user
3. Create a Python virtualenv and install packages
4. Generate an application secret key
5. Initialize the SQLite database with a default admin account
6. Create and enable a systemd service
7. Open the firewall port (firewalld or ufw)

## Configuration

### Environment Variables (`.env`)

```
SECRET_KEY=<auto-generated>
DATABASE_URL=sqlite:////opt/dba_admin_tool/dba_admin.db
FLASK_ENV=production
PORT=5000
```

### Oracle Connection via OS Environment Variables

You can pre-load Oracle credentials via environment variables in the systemd service:

```
# In /etc/systemd/system/dba_admin_tool.service [Service] section:
Environment="PRODDB_USER=system"
Environment="PRODDB_PASS=password"
```

Then reference them in the Oracle DB configuration page.

## Security

- All passwords encrypted with **Fernet symmetric encryption** (AES-128-CBC + HMAC-SHA256)
- Encryption key stored at `<app_dir>/.fernet_key` (chmod 600, owned by service user)
- Flask sessions use a cryptographically secure secret key
- All routes require login; admin-only actions are role-gated server-side
- Background tasks run in a thread pool; results persist in SQLite
